# 其他学分

::: tip 注意
**所有其他学分的实际修读要求以本专业培养方案为准**（不同专业要求可能不同）。
:::

## 美育学分

需修满 **2 学分**：线下和线上各 **1 分**。

- **线下**：到梦空间 app 自己抢活动（貌似每次加 0.2 学分）
- **线上**：选课系统自己抢，在"艺术体验与审美"这个大类

📄 官方说明：[美育学分获取方式（官方推文）](https://mp.weixin.qq.com/s/ua2MfIu-OekTyfLBSUS_Tg)

## 创新教育学分

需修满 **2 分**。

参加比赛容易获取（**从职业规划大赛获取最简单**）。

## 创业学分

很简单的办法：**中国国际大学生创新大赛**（即原来的"互联网+"），报名，然后提交一个作品（不能是空白），很大概率能加分。
