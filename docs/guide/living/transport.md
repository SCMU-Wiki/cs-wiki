# 交通

## 校内交通

**通勤手段**：

- 校内摆渡车（1R/次）
- 共享单车、共享电瓶车
- 自行车、腿（步行）

::: tip 注意
1. 共享电瓶车无法驶离校园
2. 校内禁止无牌照的电瓶车行驶
:::

- **避开高峰期**：一般只有靠南湖边的这条路会堵，绕远路从最东边的路走就行
- **事故多发地**：北书院门口的斜坡坡度 > 45°，且与南湖边主干道有视野盲区，下坡时请减速慢行（避免被送去异世界）

## 校外交通

**通勤手段**：公交、共享单车、自行车、网约车、地铁（光谷广场站离学校最近，约 2km）。

**校外骑车注意事项**：

- 光谷车流量巨大，骑车时注意安全
- 无骑行经验 / 方向感不好 / 手机电量低，请勿独自骑车探索三环线南部方向
- 东湖内骑行下坡请减速，无围栏保护
