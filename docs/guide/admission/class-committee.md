# 班委

## 班委岗位与职责

开学约一星期左右竞选班委，共 **3 名**：**班长（兼生活委员）、团支书（兼心理委员）、班级委员（兼学习委员）**（工作内容基于学长学姐的经验整理，具体请咨询班助）。

- **班长（兼生活委员）**：管理班级秩序；转发导员、班导师的重要消息到班级群；组织班级活动（如团建，部分班级会有）；关心同学日常生活
- **团支书（兼心理委员）**：负责团员、党员相关的档案收集管理；关心同学心理健康，工作相对比较轻松
- **班级委员（兼学习委员）**：每晚发线上签到统计在校人数；帮专业课老师收作业（有时是班长收）

## 竞选方式

填写报名表，无需准备 PPT。面试为多人面试：台上是本班竞选同学，台下是各班班助与导员，除自我介绍外，其余为问答环节。

## 当班委的收获与代价

- ✅ **加综测**：担任职务是综测加分项
- ✅ **锻炼能力**：组织、沟通、统筹能力都能练到，和老师、班助的接触也多
- ⚠️ **事情琐碎**：需要细心和耐心，班长尤甚——转发通知、收材料、协调班级事务，都是细活
- 💡 **竞选建议**：提前想清楚"为什么想当班委"，面试时真诚一点。没选上也不用在意，想为班级做事，任何时候都可以

## 班助是什么

班助是学长学姐（班导师助理），开学初期带你们熟悉校园、解答疑问。班级事务、竞选流程拿不准的，问班助最直接。
