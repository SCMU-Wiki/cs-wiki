---
title: 贡献指南
---

SCMU CS Wiki 是学生自发维护的社区项目，**每个人都可以贡献**，不需要会写代码。

内容难免有过时、错误或缺漏，你的一次反馈，可能帮到下一届无数人。三种参与方式，按你的情况选：

## 方式一：在线问卷（最推荐，零门槛）

不会用 GitHub？完全没关系。发现错误、想补充内容、有任何建议，填一份问卷就行，一分钟的事：

📝 **在线反馈问卷**：（制作中，即将上线，敬请期待）

问卷适合绝大多数同学：不用注册、不用学 Git，手机点开就能填。我们会定期整理问卷反馈并更新到指南里。

## 方式二：提交 Issue（有明确的问题或建议）

如果你会用 GitHub，发现内容错误、信息过时、想提出具体建议，直接在仓库提 Issue：

1. 打开 [SCMU-Wiki/cs-wiki](https://github.com/SCMU-Wiki/cs-wiki) 仓库
2. 点 **Issues** → **New issue**
3. 标题写清楚问题（如："入学必看：学费信息过时"），正文说明具体内容和来源

适合：纠错、时效信息更新提醒、功能建议。

## 方式三：提交 PR（直接改内容）

如果你会 Git 和 Markdown，欢迎直接改内容提交 PR，这是最直接的贡献方式：

1. Fork 仓库（右上角 Fork 按钮）
2. 在 `docs/guide/` 下修改对应页面的 Markdown 文件
3. 提交 PR（Pull Request），说明你改了什么、为什么改

适合：补充新内容、修正错误、优化排版。

## 内容规范（写内容前必读）

为了让指南保持高质量，提交内容时请遵守：

1. **准确性**：不确定的信息请标注"待核实"或注明来源，不要写"听说的"就当事实
2. **时效性**：政策、价格、时间等容易变的信息，请标注"以最新官方通知为准"
3. **客观**：食堂口味、个人体验类内容可以主观，但要说明是个人观点（如"个人觉得"）
4. **友善**：不攻击任何人，不写带恶意的内容；玩梗可以，别伤人
5. **格式**：用 Markdown，长段落拆成列表，信息层级清晰

## 维护团队

目前由核心维护者运营，欢迎通过问卷或 Issue 申请加入维护。

感谢每一位贡献者。**每一步都算数。** 🌱
