# 常用网站

开学后经常要用到的网站，建议先收藏：

1. **[学校官网](https://www.scuec.edu.cn/)**——官网首页，可在此找到更多校内网站入口
2. **[网上办事服务大厅（信息门户）](https://ehall.scuec.edu.cn/new/index.html?browser=no)**——各类线上事务办理
3. **[选课平台](https://xk.scmu.edu.cn/xk/profile/xk/index.html)**——选课、查课表（新系统，无需 VPN）
4. **[Web VPN](https://webvpn.scuec.edu.cn/)**——校外访问校内系统用
