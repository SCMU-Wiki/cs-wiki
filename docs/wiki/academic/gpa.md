# 绩点与综测

## 绩点——学习的"成绩单"

### 什么是绩点

绩点（GPA）是将学生课程的成绩换算成数值，直观评估学习质量。**民大的满绩是 5.0**。

📱 **查询绩点**：登录"比特工场"公众号 → 考试与成绩 → 查绩点，即可查看自己的绩点。

### 绩点怎么算

学期总绩点由课程绩点与课程学分加权计算。课程绩点根据百分制或五级制（优/良/中/及格/不及格）成绩换算：

$$
\text{课程绩点} =
\begin{cases}
(\text{课程成绩} - 50) \div 10 \times \text{课程权重系数} \quad \text{当课程成绩} \ge 60 \text{ 时} \cr
0 \quad \text{当课程成绩} < 60 \text{ 时}
\end{cases}
$$

$$\text{课程学分绩点} = \text{课程绩点} \times \text{课程学分}$$

$$\text{平均学分绩点} = \frac{\sum \text{课程学分绩点}}{\sum \text{课程学分}}$$

**百分制 ↔ 五级制**（五级制成绩对应的百分制区间）：

| 百分制 | 五级制 |
| --- | --- |
| 100-90 | 优秀（Excellent） |
| 89-80 | 良好（Good） |
| 79-70 | 中等（Average） |
| 69-60 | 及格（Pass） |
| 59-0 | 不及格（Fail） |

**两级制 ↔ 百分制**：

| 两级制 | 百分制 |
| --- | --- |
| 合格 | 85 |
| 不合格 | 50 |

### 绩点有什么用

评奖学金、保研（绩点占比约 85%）；部分招聘、升学也会考察。

## 综测——德智体美劳

### 什么是综测

全称"综合素质测评"，是对思想品德、学业成绩、科技创新、社会实践等的综合评定。

📄 官方通知：[综测评定方法与综测文件](https://www.scuec.edu.cn/stu/info/1575/8112.htm)

### 综测怎么加

获取综测的途径包括但不限于：参加各类校园活动、做志愿服务、参加比赛、比赛获奖、运动会、担任职务（课代表除外）。

活动结束后发出的综测证明或其他可证明材料（奖状、聘书等）**请自行保管好**，需在规定时间（秋季开学这段时间）登录"综合素质测评系统"上传证书、证明等材料申报。

### 综测有什么用

奖学金评选、评优评先、保研，占比不大不小。
