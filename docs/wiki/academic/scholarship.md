# 奖助学金

## 奖学金评选标准

评奖学金看这三样：

| 项目 | 占比 |
|---|---|
| 学分绩点 | 60%~70% |
| 综测 | 20% 左右 |
| 早晚签 | 10% 左右 |

评选时间：暑假开学后。

**前置条件**：

1. 一年内无挂科（学业进步奖除外）
2. 每学期早签的缺勤次数在规定范围内
3. 体测成绩达标

::: tip 注意
- 国家奖学金与国家励志奖学金**不可兼得**；学业奖学金与学业进步奖学金**不可兼得**
- 评奖当年，其上一学年不可有挂科（学业进步奖除外）
- 上学年体测未达良好以上（测试得分除外）或有挂科，无当年评奖资格
:::

## 奖学金一览

| 类型 | 金额 | 主要条件 |
|---|---|---|
| 国家奖学金 | 10000/人 | 特别优秀，专业前 10% |
| 国家励志奖学金 | 6000/人 | 品学兼优，必须家庭经济困难，专业前 30% |
| 优秀学生奖学金（学业奖学金） | 1400/人 | 均分 75+，综测专业前 50%，四级 > 425 |
| 一/二/三等奖学金 | 以官方通知为准 | 均分 75+，综测专业前 50%，四级 > 425 |
| 学业进步奖学金 | 600/人 | 根据综测排名进步百分比评选 |
| 先进集体 | 1000/班 | 挂科率 < 10%，无作弊，早签 > 90%，体育达标率 100% |
| 先进个人 | 500/人 | 均分 85+，四级 > 425 |

**其他专项奖学金**：

| 类型 | 金额 | 主要条件 |
|---|---|---|
| 文体佳绩奖学金 | 600/人 | 非常严苛：德智体美劳全面发展 + 科研表现突出（专利、学科竞赛、一作论文，成绩专业前 20%） |
| 社会实践奖学金 | 4000/人 | 均分 70+，综测专业前 60% |
| 吴泽保奖学金 | 3000/人 | 同上 |

（以上摘自《奖学金种类及金额一览》，以学校最新通知为准。）

## 助学金

需为**认定家庭经济困难**的学生，分为三档：**一般困难、困难、特别困难**。家庭经济困难认定是助学金及部分奖学金（如国家励志奖学金）的前提，入学后关注通知申请。

**国家助学金**（按认定档次发放）：

| 档次 | 金额（每学年） | 发放方式 |
| --- | --- | --- |
| 一般困难 | 2800 元 | 每学年发放，一个学期打一半 |
| 困难 | 3300 元 | 同上 |
| 特别困难 | 3800 元 | 同上 |

::: tip 注意
**25 级新增**：助学金申请需要志愿时长 **> 15 小时**。
:::

**其他相关资助**：

| 类型 | 金额 | 说明 |
| --- | --- | --- |
| 仁东奖学金 | 2000-3000/人 | 家庭经济困难，名额有限，学院报送全校竞选 |
| 多维奖学金 | 2000/人 | 同上 |
| 海东助学金 | 5000/人 | 极其严苛，优先重大疾病或残障的大一新生 |

## 勤工助学岗

- **360元/月**，自行在信息门户申请，一人只能报一个岗位，需为家庭经济困难学生

## 奖学金发放

奖学金会在一段时间后发至随录取通知书送到的农业银行银行卡上（有点久，但不会不发的，放心）。
