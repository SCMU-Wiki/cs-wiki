# 四六级及英语免修

## 听力试听

四六级开考前 2-3 周的工作日，学校每天都会在频道播听力，频率与四六级一致：**FM84.2**，记得考前给耳机充好电。

## 英语免修 —— 给自己更多课余时间！

四六级通过（≥ 425 分）即可在下一学期申请英语课免修，但不同年级可免修的课程不同，是顺着大家的培养方案走的。

四六级换算免修英语课程成绩公式（不同学期系数可能调整，以当学期官方通知为准）：

| 学期 | 分数换算 |
| --- | --- |
| 2025-2026 第一学期 | `分数 / 710 × 117` |
| 2025-2026 第二学期 | `分数 / 710 × 125` |


**官方免修通知会在每学期开学不久后发布，班委会进行转发，这里先参考上一学期的：** [关于组织开展2025-2026学年度第二学期大学英语课程免修申请工作的通知](https://www.scuec.edu.cn/jwc/info/1003/3949.htm)
