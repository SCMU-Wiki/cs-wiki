# 校园卡

## 用途

校内超市、食堂支付，开寝室门，洗澡，进图书馆等。

## 微信 / 支付宝绑定

用微信或支付宝**扫码消费**前，需要先完成绑定。

### 微信扫码消费（2 步）

1. 企业微信须与微信绑定：【企业微信 → 我 → 设置 → 账户 → 微信】
2. 企业微信与校园卡绑定：【企业微信 → 工作台 → 校园卡】，绑定后即可使用微信付款码消费

### 支付宝扫码消费（4 步）

1. 打开支付宝，搜索"中南民族大学生活号"
2. 点击并关注该生活号
3. 进入生活号，点击"校园卡绑定"
4. 输入对应的信息，完成校内身份认证

## NFC 绑定

手机设置里搜索并打开 NFC，将校园卡贴近 NFC 感应区。

## 校园卡丢失处理办法

1. 寻找
2. 到学校 4 号楼（不是宿舍），乘电梯至 5 楼，出电梯第一个房间就是补办地点，需缴纳 20R 手续费
