# 实验室

大多数实验室会在**秋季招新**，主要对象为大一新生（也会有春招，但名额会减少）；部分实验室只招大二生，但不多。

- 大多数实验室**不限制专业**加入（部分专业有推荐报名）
- 有意向加入实验室的同学建议**大一上就开始准备**

## 新思路实验室（计算机专业占比略大）

- 专业不限，任何学院都可以
- 学习路线因各个组的不同而不同
- 会参加比赛，没有强制，但在实验室会比较方便组队
- 平时工作：不当组长就是打卡和参加分享会汇报学习进度；当组长则要开会对接项目、进行组员技术指导

官网：<https://recruit.new-thread.com>

## 电赛实验室（自动化居多）

电赛实验室是学院备战全国大学生电子设计竞赛的专属集训基地，面向学院所有学生开放，秉持**以赛促学、软硬结合**的培养理念：

- 配备示波器、稳压电源、恒温焊台等专业测试仪器，STM32、视觉模块、电机、红外灰度传感器等全套开发器材及 PCB 设计、3D 打印设备
- 聚焦控制、电源、测控三个组别，采用自学 + 高年级队员帮带的阶梯式培养模式
- 全天候开放工位并统一提供元器件耗材，多年来累计斩获多项国赛、省赛奖项

## 轨道交通虚拟仿真实验室

🚇 计算机学院轨道交通虚拟仿真实验室招新！面向计算机学院 & 美术学院全体新生。

**五大技术方向 · 同款大作引擎体验**

1. **虚幻引擎部**：UE5 蓝图 / C++——《黑神话：悟空》级影视画质、《鸣潮》式大世界交互
2. **Unity 部**：C# / Unity——驾考模拟器、《原神》开放世界同款引擎，快速做出你的第一个小软件
3. **建模部**：Blender + PS——高精度建筑复刻、材质渲染
4. **云渲染部**：WebUI + Web3D——从零搭建个人网站界面，让《Roblox》《我的世界》秒开即玩
5. **人工智能部**：Python + 深度学习——复活《桌面宠物》《智能 NPC》

你将收获：真实项目经验、每年保底国奖省奖、例会演讲与团队协作、代码 × 美术双修。基础可以慢慢攒，热情与坚持最珍贵。
