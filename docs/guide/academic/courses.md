# 选课

## 课程结构

大学的课程大致分为公共课程、专业课程、选修课程，想毕业需要修够一定学分（具体以本专业培养计划为准，可在教务系统查询）。

如多选选修课程，大四就会轻松很多，甚至一周只有一两节课。

## 选课系统

学校上学期末推出了**全新的选课系统**，终于不用 VPN 里的那个老系统了：

- 网址：<https://xk.scmu.edu.cn/xk/profile/xk/index.html>（以教务系统最新通知为准）
- **体验**：非常丝滑，实测**不需要校园网**也很快——系统部署在公网

## 温馨提示

- 如遇验证码输入无效，说明选课服务尚未正式开放，正式选课前验证码功能会恢复正常
- 选课前建议先查看本专业**培养计划**，了解课程安排与学分要求（可在教务系统查询）

## 选课妙招

如在校内，到**教学区**而非生活区选课。
