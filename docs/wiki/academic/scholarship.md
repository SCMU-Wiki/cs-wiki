# 奖助学金

## 奖学金评选标准

奖学金每学年评选一次，**一般在秋季学期集中评选**。评选主要看**上学年加权平均成绩**和**综合素质测评**，各奖项的具体条件见下表。

**参评基本条件**（以下任一情况无当学年度参评资格）：

1. 上学年因违反校纪校规受到纪律处分
2. 上学年大学生体质健康测试成绩未达良好以上（免试学生除外）
3. 上学年存在课程不及格
4. 上学年休学、保留学籍
5. 未按规定缴纳学费及有关费用

::: tip 不可兼得规则
- 同一学年内，国家奖学金与国家励志奖学金**不可兼得**
- 校设综合评价奖学金与单项奖学金**不可兼得**；同一类型校设奖学金**不可兼得**
- 吴泽霖奖学金与校长奖学金**不可兼得**
:::

## 奖学金一览（2025 年修订版）

**政府奖学金**：

| 类型 | 金额 | 主要条件 |
| --- | --- | --- |
| 国家奖学金 | 10000/人 | 加权平均成绩与综测均居年级专业前 10% |
| 国家励志奖学金 | 6000/人 | 家庭经济困难，加权与综测居困难生前 30% |

**校设奖学金**：

| 类型 | 金额 | 主要条件 |
| --- | --- | --- |
| 校长奖学金 | 10000/人（每年 ≤ 10 人） | 综合素质最优秀或有突出贡献 |
| 校长提名奖学金 | 5000/人（每年 ≤ 10 人） | 某方面突出特长或贡献 |
| 国防奖学金 | 3000/人 | 参军入伍的退伍学生 |
| 国防贡献奖学金 | 5000/人 | 部队荣立三等功及以上 |
| 精神文明奖学金 | ≥ 1000/人 | 民族团结、见义勇为等典型事迹 |
| 吴泽霖奖学金 | 一等 5000 / 二等 4000 / 三等 3000（每年 ≤ 8 人） | 智育成绩专业前五 + 科研创新突出（四级 497+ 或六级 426+） |
| 优秀学生奖学金 | 一等 2000（3%）/ 二等 1500（7%）/ 三等 1000（15%） | 加权平均 75+，综测前 50%；三年级起一、二等需四级 426+ |
| 学习进步奖学金 | 600/人（2%） | 综测进步名次靠前 |
| 文体佳绩奖学金 | 500/人（2%） | 文体技能比赛取得优秀成绩 |
| 社会工作奖学金 | 500/人（2%） | 学生组织任职期间成绩突出 |
| 社会实践奖学金 | 500/人（2%） | 社会实践表现突出 |

（文体佳绩、社会工作、社会实践奖学金共同条件：加权平均 70+，综测前 60%。）

**社会奖学金**：企事业单位、社会团体及个人捐赠设立，评选条件与标准以捐赠协议为准。

## 助学金

需为**认定家庭经济困难**的学生，分为三档：**一般困难、困难、特别困难**。家庭经济困难认定是助学金及部分奖学金（如国家励志奖学金）的前提，入学后关注通知申请。

**国家助学金**（按认定档次发放）：

| 档次 | 金额（每学年） | 发放方式 |
| --- | --- | --- |
| 一般困难 | 2800 元 | 每学年发放，一个学期打一半 |
| 困难 | 3300 元 | 同上 |
| 特别困难 | 3800 元 | 同上 |

::: tip 注意
**25 级新增**：助学金申请需要志愿时长 **> 15 小时**。
:::

**其他相关资助**：

| 类型 | 金额 | 说明 |
| --- | --- | --- |
| 仁东奖学金 | 2000-3000/人 | 家庭经济困难，名额有限，学院报送全校竞选 |
| 多维奖学金 | 2000/人 | 同上 |
| 海东助学金 | 5000/人 | 极其严苛，优先重大疾病或残障的大一新生 |

## 勤工助学岗

- **360元/月**，自行在信息门户申请，一人只能报一个岗位，需为家庭经济困难学生

## 奖学金发放

奖学金经财务处以银行转账方式发放至学生，获奖学生统一发文表彰、颁发荣誉证书。
