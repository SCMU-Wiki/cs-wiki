# 其他事项

学费分为住宿费、学分费，其中学分费是先选课后缴费的，缴费二维码到时候导员或者班助、班导师、班长会发。

## 分级教学（数学 / 英语分班）

入学后有**分级教学**：数学和英语都会分班，教学难度和进度不同。

- **数学**：以开学考成绩分班，分为 **A/B/C 班**（考试时间在开学不久）
- **英语**：根据高考英语成绩分班，分为 **A/B 班**

数学开学考内容（据 25 级学长回忆）：

- 基本上是**中低档的高中题目**，不难
- **函数和导数**考得最多，**数列**考得第二多
- 不等式、集合等零碎板块也有涉及
- **没有**圆锥曲线和立体几何，概率也几乎没考
- 有三四个小题涉及**高数知识**（最简单的求极限、极坐标），分数占比很小，但可以提前留意

## 转团（团组织关系转接）

内容摘自《新生手册》。时间在开学一星期内，具体以班委/班助通知为准。新生团员需完成**线下 + 线上**两步转接：

**准备材料**：

- 团员档案：入团申请书、入团志愿书等，需**密封盖章**；如不齐全须回原入团单位补办
- 团员证：由本人持有

**线下转接**：将团员档案交给所属学院，由学院统一办理团组织关系转入手续。

**线上转接**：本人登录**智慧团建**系统，完成团组织关系转接操作。

## 贫困申请

建议提前准备好贫困的证明材料以及复印件（比如家里有亲属患病之类的）。

::: tip 注意
- **励志奖学金**的评选与**国家奖学金**独立，励志奖学金会相对少一点
- 家庭非贫困的同学请勿谎报，占用公共资源 🌹🌹
:::

## 教材订购

大一上教材均为学校统一订购，无法退订。此后每学期教材均可退订，建议退订后自己网上买或者从书店淘二手的，也可以礼貌向高年级询问是否有二手。

## 请假

在节假日或放假前夕，倘若没有课程，部分同学会选择请假（**提前离校必须请假**）。

假条需要有**监护人身份证的正反面照片**。
