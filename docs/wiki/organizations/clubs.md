# 其他组织与社团

## 百团大战

国庆放假回来后，**一二食堂附近** 和 **操场** 会举办"**百团大战**"——全校社团集中宣传招新，是了解学校社团文化的最好机会。

- **时间**：国庆回来后
- **地点**：一二食堂附近和百团大战——南湖操场
- **形式**：各社团摆摊宣传，现场报名

## 社团类型参考

百团大战上常见的社团大致分几类（不全）：

- **学术科技类**：编程、机器人、数模、辩论等，和专业/竞赛相关
- **文化艺术类**：音乐、舞蹈、摄影、书画、文学等
- **体育竞技类**：球类、跑步、健身、武术等

## 小建议

- 逛百团大战**别急着报名**，先逛一圈，看看哪个社团的活动你真心感兴趣
- 社团**不在多**，一两个就够，能坚持参加才有意义
