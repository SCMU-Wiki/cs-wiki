# 体测

## 体测地点

- 室内地点：体育训练中心一楼（17 号教学楼）
- 室外地点：南湖操场

## 体测项目

- **室内**：体重、肺活量、立定跳远、坐位体前屈、引体向上（难）/ 仰卧起坐（女）
- **室外**：50m、1000m（男）/ 800m（女）

## 体测次数

至少进行四次体测：

1. 大一上测大一的
2. 大一下测大二的
3. 大二学年测大三的（一学年可测两次，可只测一次，以最高的算）
4. 大三学年测大四的，大四无

## 注意事项

::: warning 注意
- 体测需携带身份证
- 体测分数未达标将无法参加奖学金评选，拉不起引体的有福了
:::
